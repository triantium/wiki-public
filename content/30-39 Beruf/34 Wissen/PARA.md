# PARA

PARA is a personal knowledge management framework by Tiago Forte that sorts all information into four categories:

**Projects** (active efforts with a defined goal),
**Areas** (ongoing responsibilities),
**Resources** (reference material), and
**Archives** (inactive items).

The most useful boundary is between Projects and Areas: a project has a defined outcome and an end, while an area does not.
Keeping that distinction sharp prevents a system from filling up with vague, perpetually open work.
